** Font Family
Settings related to fonts within Doom Emacs:

+ ~doom-font~ - Standard monospace font that is used for most things in Emacs.
+ ~doom-variable-pitch-font~ Variable font which is useful in some Emacs plugin.
+ ~doom-big-font~ - Used in ~doom-big-font-mode~; useful for presentation.
+ ~font-lock-comment-face~ - for comments.
+ ~font-lock-keyword-face~ - for keywords with special significance like ~setq~ in elisp.

#+begin_src emacs-lisp :tangle yes
; NOTE: Setting Basic Font Family and Font Size
(setq doom-font (font-spec :family "JetBrainsMono Nerd Font" :size 15 :weight 'normal)
      doom-variable-pitch-font (font-spec :family "JetBrainsMono Nerd Font" :size 15 :weight 'normal)
      doom-big-font (font-spec :family "FiraCode Nerd Font" :Font 18 :weight 'normal))

; NOTE: Basic font style
(after! doom-themes
  (setq doom-themes-enable-bold t
        doom-themes-enable-italic t))

; NOTE: Custom font faces for text
(custom-set-faces!
  '(font-lock-comment-face :slant italic)
  '(font-lock-keyword-face :weight bold)
  '(font-lock-function-name-face :weight bold))
#+end_src

** Global Auto Revert
A buffer can get out of sync with respect to its visited file on disk if that file is changed by another program. To keep it up to date, you can enable Auto Revert mode by typing M-x auto-revert-mode, or you can set it to be turned on globally with ‘global-auto-revert-mode’.  I have also turned on Global Auto Revert on non-file buffers, which is especially useful for ‘dired’ buffers.
#+begin_src emacs-lisp :tangle yes
; NOTE: global revert mode settings
(setq global-auto-revert-mode 1)
(setq global-auto-revert-non-file-buffers t)
#+end_src

** Tree-sitter
Doom's built-in =:tools tree-sitter= module handles grammar installation and
mode remapping (including Lua's =lua-mode= to =lua-ts-mode=), so the external
=treesit-auto= package is no longer needed. This hook ensures LSP also starts
in tree-sitter shell buffers such as =bash-ts-mode=.

#+begin_src emacs-lisp :tangle yes
; NOTE: Ensure LSP also starts in tree-sitter shell buffers (e.g. .bashrc)
(after! sh-script
  (add-hook 'bash-ts-mode-local-vars-hook #'lsp! 'append))
#+end_src

* Email
Setting up my email client

  (setq mu4e-root-maildir (expand-file-name "maildir/gmail" my/mail-dir)

        mu4e-trash-folder  "/[Gmail]/Trash"
        mu4e-refile-folder "/[Gmail]/All Mail"

        user-mail-address "harshv5094@gmail.com"
        user-full-name    "Harsh Vyapari"

        ;; Send through Gmail SMTP; credentials come from auth-sources

        smtpmail-smtp-server       "smtp.gmail.com"

* RSS
My RSS feeds are read with elfeed, provided by Doom's ~:app rss~ module with the
~+org~ flag. The feeds themselves live in [[file:elfeed.org][elfeed.org]] next to this config.
** Elfeed
The ~:app rss~ module defaults to reading feeds from ={org-directory}/elfeed.org=,
so point it at the file in my Doom config directory instead.
#+begin_src emacs-lisp :tangle yes
; NOTE: Elfeed RSS reader
(setq rmh-elfeed-org-files
      (list (expand-file-name "elfeed.org" doom-user-dir)))

; Setting search feed to one month ago
(setq elfeed-search-filter "@1-month-ago")
(add-hook 'elfeed-search-mode-hook #'elfeed-update)
#+end_src
